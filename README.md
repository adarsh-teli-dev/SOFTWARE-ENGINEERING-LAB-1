# Lab 1: Requirements Engineering & UML Use-Case Modelling

## Problem Statement

**Student Club Event Ticketing & Budget Portal**

This project contains the requirements and UML modelling work for Lab 1 of the Software Engineering course.

The system is intended to support student clubs in submitting event proposals, requesting university budget allocations through the approval process, and managing secure QR-code tickets for event attendees.

## Contents

* **Requirements Table**
  Contains 5 Functional Requirements (FR-001 to FR-005) and 2 Non-Functional Requirements (NFR-001 and NFR-002), along with their priorities, acceptance criteria, and rationale.

* **UML Use-Case Diagram**
  Shows the main actors, system use cases, associations, and `«include»` / `«extend»` relationships.

* **Use-Case Flow**
  Describes the preconditions, main success scenario, alternate flow, and postconditions for one core use case.
